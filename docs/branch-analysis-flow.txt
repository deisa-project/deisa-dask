Worked example:  def cb(arr, window): n = arr.sum(); f = (arr*arr).mean(); n.compute(); f.compute()

  Stage 2 records: [sum-expr graph, mean-of-square graph]
  Stage 3 emits:   hint1 {output_key="f-sum",        op=sum,  kind=scalar}
                   hint2 {output_key="f-mean",       op=mean, kind=mean,  chunk_func=mean_chunk{"n","total"}}
  Stage 4:         hint1 -> chain [sum]           len 1 -> deliver_direct=True
                   hint2 -> chain [mul, mean]     len 2 -> deliver_direct=True
                            (mul proven chunk-local pointwise; callback sees arr*arr rebuilt)
  Result: 2 BranchSpecs, no full chunk ever crosses to a worker.
